A useful agent is not one that can call every tool. It is one that knows which tool is appropriate, what context it needs and when a person should approve the next step.

## Start with a clear job

Give each tool a specific purpose and a small, well-defined input. Clear boundaries make it easier to understand what an agent can do, test its decisions and improve the workflow when something changes.

## Keep people in the loop

Read-only checks and reversible actions can often be automated. Changes with a meaningful cost or customer impact should have a clear review point, with enough context for a person to make a useful decision.

Good automation is not about removing every human step. It is about taking care of the repetitive work while making important decisions easier to see and safer to make.
