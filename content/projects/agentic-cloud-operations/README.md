## Context

Cloud operations requests need clear intent, relevant diagnostic evidence and controlled execution. This reference project describes an approach informed by my engineering experience.

## Approach

- Route tasks based on intent and available context.
- Integrate diagnostic tools through MCP.
- Require human approval before high-impact actions.

## Outcome

A workflow concept that keeps investigation and approval steps explicit. No public demo or measured project outcome is claimed here.
